# 第二册生活运用：覆盖与验收

新增 96 课，4 个阶段；862 条词表项（839 种拼写），576 道原创主练习，1066 道自动生成的课后词测。保留原有325个英语任务、250项词汇和325段离线MP3。

## 教学设计

- 面向中国初高中学生，中文讲解和翻译，原创校园、家庭、购物、出行、社区与数字生活场景。
- 每课：讲解和目标词例句 → 原创短文/对话 → 6道语法、理解与表达练习 → 词汇复习 → 逐题词测。
- 四阶段增加篇幅和表达复杂度；原书语法本身循环复习，复习课不会被误称为新语法章节。
- 所有映射目标词都有原创例句及测试。词性、词义按来源核对；较少见、历史性或专名词汇说明使用场景。
- 小词测覆盖词义、缺1–2字母、已学句子中的用词，以及适合实物的看图选词。抽象词不强配误导图。
- 错题有解释且可重试，先前答对项保留；新课完成需主练习和词测均通过。

## 兼容与素材

- 两条英语路线分别保存进度，用一个英语备份导出/导入。
- 旧英语/法语课的ID、主练习、插图和音频保留；新增每节课后的短词测不会取消旧完成记录。

## 验收命令与边界

- `node --test tests/english-life-course.test.mjs tests/english-life-progress.test.mjs tests/language-vocabulary.test.mjs tests/language-vocabulary-pictures.test.mjs`：96课与862词的完整映射、576题答案/干扰项、逐词覆盖、解锁、存档和图片规则。
- `GRAY_CROWN_JSDOM=/path/to/jsdom/lib/api.js node --loader ./tests/helpers/ignore-css.mjs tests/language-ui-dom.mjs`：真实组件的DOM模拟，覆盖主课→词测、空答/错答/重试、法语重音、保存失败重试、已完成主课重练、两路线切换、备份导入和重置。需要已有jsdom，缺少会明确失败。
- `node --test tests/*.test.mjs`：全库JavaScript回归。
- `npm run test:browser`：完整浏览器、音频和布局验收，需先完成项目规定构建。

本次环境可做Node和DOM模拟；完整浏览器受沙箱socket限制。公开构建缺完整Clang LFS资源，桌面构建缺.NET9/wasm-tools，C编译回归缺@wasmer/sdk，Rust工具链不可用。未以模拟DOM或SVG预览代替真实浏览器/音频验收，未合并或部署。
