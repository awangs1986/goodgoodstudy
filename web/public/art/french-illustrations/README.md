# French A1 PNG illustrations

Original AI-assisted commercial-cartoon artwork generated for this project with OpenAI's built-in image generation. Each asset was generated individually, viewed, and prepared as a reusable PNG. No third-party character or brand was requested.

- 12 painted Paris backgrounds, 960×600
- 9 recurring people plus Gribouille, transparent 400×600
- 58 everyday props, transparent 256×256 (30 appear in the current question scenes; all existing API keys remain supported)
- 7,806,441 bytes total (7.81 MB decimal), reused across 156 lessons and 416 question scenes

The PNGs include no lesson text or answers. Captions, bubbles and other instructional text are live HTML. Backgrounds are scenery only; people and selected props are independent layers. Character identity colors, age markers and accessories follow the pre-existing cast. Inès's ponytail and Luc's moustache were checked and corrected with targeted image edits.

See PROVENANCE.json for every full generation prompt, targeted correction prompt, dimensions, byte count and SHA-256. The locally retained original generations are higher resolution; the repository ships display-sized assets to keep downloads bounded. Preparation used only image resizing, framing, padding and PNG compression after generation.

Rendering, semantic boundaries and verification instructions are documented in ../../../courses/french-a1/ILLUSTRATIONS.md and ../../../courses/french-a1/ILLUSTRATION_SEMANTICS.md. The standing sprites do not recreate all decorative SVG pose/expression variants.
